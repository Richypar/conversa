¿Cómo consigo la clave? (solo hay que hacerlo una vez)
  1. Entra en console.deepgram.com y crea una cuenta (regalan 200 $ de saldo, más de un año de uso).
  2. En el menú, abre API Keys y pulsa Create a New API Key.
  3. Copia la clave y pégala arriba.
🔒 Privacidad: la conversación no se guarda en ningún sitio. Al cerrar la aplicación se borra todo. Solo la clave y tus preferencias de letra y tema quedan guardadas en esta tablet.
