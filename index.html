¿Cómo consigo las claves? (solo hay que hacerlo una vez por motor)
  1. Deepgram: cuenta en console.deepgram.com (200 $ de regalo) → API Keys → Create a New API Key.
  2. Speechmatics: cuenta en portal.speechmatics.com (100 $ de regalo) → API Keys → crear clave.
Si el micrófono capta lejos o con ruido, prueba a desmarcar los filtros de voz.
🔒 Privacidad: la conversación no se guarda en ningún sitio. Al cerrar la aplicación se borra todo. Solo las claves y tus preferencias quedan guardadas en esta tablet.
